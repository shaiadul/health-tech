# Health-Tech Monorepo

Project workspace containing frontend and backend services.

## Repository Structure

```
health-tech/
├── frontend/    # Next.js web application
└── backend/     # Backend service (empty)
```

## Quick Start

### Frontend
Navigate to the `frontend` directory:
```bash
cd frontend
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the application.

### Backend
The `backend` directory is initialized for future backend services.
